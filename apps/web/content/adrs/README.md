# Architecture Decision Records (ADR)

How this system is built and why. Every decision that changes the architecture gets written down.

## Conventions

- Directory: `adr/`
- Naming: `NNNN-title-with-dashes.md`
- Status values: `proposed`, `accepted`, `rejected`, `deprecated`, `superseded`
- ADRs are written to be agent-executable — a coding agent should be able to implement from the ADR alone
